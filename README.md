# Kelvanic Homebrew Tap

```sh
brew tap kelvanic/tap
brew trust kelvanic/tap   # Homebrew 6+ asks once for third-party taps
brew install --cask deckle
```

| Package | Description |
|---|---|
| [deckle](https://github.com/Kelvanic/deckle) | Paper-grain texture overlay that makes your screen feel like paper |
