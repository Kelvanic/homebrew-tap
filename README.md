# Kelvanic Homebrew Tap

Apps from [Kelvanic](https://kelvanic.com), an independent software studio.

```sh
brew tap kelvanic/tap
brew trust kelvanic/tap   # Homebrew 6+ asks once for third-party taps
brew install --cask deckle
```

| Package | Description |
|---|---|
| [deckle](https://kelvanic.com/products/deckle/) | Paper-grain texture overlay that makes your screen feel like paper |
